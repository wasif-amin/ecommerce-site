Description: A decoupled e-commerce platform with a Python API backend, React storefront, and persistent cart. Built to handle real payments and real image uploads.

Features I'm proud of:
- session based carts that persist across reloads and his user specific
- stripe checkout for order fulfillment
- Feature-branch Git workflow - every feature built on its own branch, PR merged to main


Tech Stack
- Frontend: React, React Router, Axios
- Backend: Python (Flask), REST API, Session Auth
- Database: PostgreSQL
- Tools: Git, dotenv
- Payment Processing: Stripe
- Media Management / Cloud Storage & CDN: Cloudinary
