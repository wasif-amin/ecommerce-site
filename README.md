Project: Niche e-commerce store: [Demo](https://ecommerce-site-git-main-wasif-amins-projects.vercel.app/) **PLEASE ALLOW 1-2 MINUTES FOR SEVER TO LOAD**

Description: A decoupled e-commerce platform with a Python API backend, React storefront, and persistent cart. Built to handle real payments and real image uploads.

Features I'm proud of:
- session based carts the process across reloads and his user specific
- stripe check out for order fulfillment(no frontend-only check out)
- Feature-branch Git workflow - every feature built on its own branch, PR merged to main


Tech Stack
- Frontend: React, React Router, Axios
- Backend: ython (Flask / FastAPI), REST API, Session Auth
- Database: PostgreSQL
- Tools: Git, dotenv
